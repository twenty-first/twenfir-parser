twenfir-parser
==============
A support library for parser development
----------------------------------------
![build](https://github.com/twenty-first/twenfir-parser/actions/workflows/build.yml/badge.svg)

Currently provides common classes for the ddsparser and prtfparser parsers. Still work in progress. 
Semantic versioning will be supported, but no guarantees are given as long as version is in the 
0.0.x range. 

`twenfir-parser` is available from the Maven Central repository.
